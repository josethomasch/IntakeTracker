# Intake Tracker (Android Tablet App)



An offline-first Android tablet application designed for patient intake management (Medicines and PEG feeds).



## Features

- **Combined Daily View:** Displays both Medicines and PEG feeds together in chronological order.

- **Multi-Tab Regimen Plans:** Toggle between Standard Plan, Alternate Pattern, and Flush / Light Day.

- **Batch Scheduling:** Add multiple medicines and feeds assigned to the exact same time slot in one dialog.

- **Manual Touch Logging:** Tap tasks to mark complete. Stores logs locally in SQLite.

- **Daily Isolation:** Logs use start/end-of-day bounds, automatically resetting completed status at midnight.
